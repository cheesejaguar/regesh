# Initial exploratory pilot

An initial implementation run logged hybrid mean quality 0.6324287710086077 and
ordinary mean quality 0.6268835197476842. Raw pilot results were accidentally
overwritten when a corrected run began in the same output directory before the
initial process completed. These log-only pilot means are excluded from the final
evidence; no raw pilot archive is claimed or reconstructed.

Independent code review identified a weaker direct comparator (only one of four
stored heads affected selection), delayed visibility of a revised constraint,
a missing affect-specific retrieval ranking, unmatched ignored prediction work,
and a heuristic replacement in the no-counterfactual condition. Structural fixes
were made without optimizing held-out scores. The corrected study is exploratory,
not a preregistered or independent confirmatory experiment.
