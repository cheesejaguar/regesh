# Local interfaces

Run `python -m regesh demo --db demo.sqlite`, then `python -m regesh inspect --db demo.sqlite` and open the printed loopback URL. The inspector displays journal-order mood trajectories, triggering records, appraisal versions, memory, controls, and full state. Fork, replay, state intervention, and simulation-time advance are available. All changes are journaled. It binds only to loopback and requires an unpredictable per-server token plus same-origin requests for writes. Do not expose this research service publicly.

`python -m regesh state --db demo.sqlite` returns full JSON. `snapshot --output saved.json`, `restore --input saved.json`, `fork --target other`, `replay --target replayed --through 3`, `trace --output trace.json`, and `export --output inspector.html` support offline work. Static export is an inspection artifact; its mutation buttons need a running inspector.

`python -m regesh intervene --db demo.sqlite --changes '{"mood":{"valence":0.4}}' --reason 'controlled perturbation'` performs an explicit intervention. Use a fork to preserve the comparison condition.

`python -m regesh model --db demo.sqlite --prompt 'Suggest a constraint-aware design'` uses the deterministic fixture. For a compatible running server, configure `REGESH_MODEL_BASE_URL=http://localhost:8000/v1` and `REGESH_MODEL_NAME` to its actual served model, then add `--live`. Set `REGESH_MODEL_API_KEY` only when the server requires authentication. The adapter neither provisions credentials nor assumes a GPU. Every successful call retains the exact JSON request, raw response, parsed response, model/seed/budget, usage when supplied by the server, and elapsed time. Auth headers are excluded. Server identity/version beyond its returned model identifier must be captured by the experiment operator.

`LocalChatModel.complete(..., recorder=agent.record_artifact)` journals a model call. Use `agent.record_artifact('tool_result', result)` for exact tool output. `ModelAppraisal(LocalChatModel(...))` may be passed as `appraisal_provider` to `Agent`. Its complete model trace is embedded in each accepted appraisal. Numeric ranges, evidence references, and alternatives are validated. This establishes schema compliance, not truth about intent. Model output never changes the observation record or supplies an observed outcome. `ProviderError.record` retains malformed responses; after an `observe` failure/rollback, explicitly journal it if required.

`examples/agent_loop.py` shows observation, controls, evidence retrieval, generation, allocation, independently labeled fixture check, outcome, and snapshot integration. Its fixture check is not a creativity benchmark.

`python -m regesh train --output results/training` trains the small simulator predictor. `python -m regesh benchmark --output results/benchmark` runs the declared procedural comparisons. These commands do not call a language model. `python -m regesh core-eval --output results/core` runs the fixed core history/intervention measurements. Default replay recomputes transitions from recorded observations/appraisals without calling providers and checks poststates. Live provider re-execution is a separate experiment.
