# Persistent developing affect: implementation and exploratory evidence

**2026-10-25.** Regesh is a working local platform and an executed small research study. Functional persistence, development and causal cognitive effects are demonstrated in deterministic histories. **The learned affect mechanism did not demonstrate superior useful solution generation over ordinary adaptive control.** Architectural priority, real-LLM creativity, psychological validity, biological fidelity and subjective experience remain unestablished.

## What was built

Python SDK, SQLite atomic per-agent state/journal, typed versioned evidence, separate interpretation revisions and outcomes, deterministic reference appraiser, fast mixed target-specific components, slow mood/relationships/dispositions, learned task expectations and factual reliability, an operational resource profile, evidence-focused and affect-modulated memory, five cognitive control outputs, explicit executed resource costs, snapshots/restores/forks/reset, causal interventions, and deterministic transition recomputation from recorded appraisals. A loopback inspector shows trajectories, triggers, interpretation versions, memories, controls and journal entries. Model/tool artifacts retain exact payloads; optional local compatible model adapters and deterministic fixtures are implemented.

One experimental mechanism is fully implemented: a learned action-consequence predictor scored by current operational state to regulate exploration, refinement, combination and verification. It is trained from simulator outcomes with ridge regression on CPU. Both the learned adapter and weights can be attached to the durable platform; its simulator evaluation uses a separate explicit per-trial search state. Four learned consequence heads are not a learned biological emotional organ. Strategy-to-control maps are hand-authored; the candidate hypothesis of separately learned process-specific modulation receptors was not completed or claimed as a second result.

All **64 tests pass**, including an isolated accurate/misleading-criticism history that changes future source uncertainty while holding task quality and affiliation fixed. Installation, demo, inspector and all experiments are documented in the [README](../README.md). The runtime had Python 3.12.14, NumPy 2.3.5, five Intel Xeon virtual CPU cores and about 17 GiB memory. No CUDA/PyTorch runtime, model credential, model endpoint, research map/PDF, human dataset or participant resource was available. Conventional local ports 8000 and 11434 had no model service. No paid resource or external model call was used. GitHub access was available. Only README/license existed initially; no preexisting code or user changes were overwritten.

## Frontier, competition, and possible originality

The [matrix](research_matrix.md) checks 28 primary-source comparisons, publication status, code, supporting evidence and verification limits. ALMA and EMA precede layered affect and appraisal/coping. WASABI and FAtiMA implement affect dynamics and action influence. Generative/Humanoid Agents precede persistent agent memory, needs and relationships. Sentipolis is particularly close for continuous persistent state, dual timescales and memory coupling. PsychoAgent separates factual and affective memory and uses executive conflict control. Chain-of-Emotion and newer appraisal architectures precede structured LLM appraisal. Homeostatic RL, EVAAA, active inference, learning progress and rational metacontrol precede internally sensitive action regulation. LLM causal emotion-vector research means the base model cannot be treated as emotionless.

The [competition memo](hypotheses.md) records ten candidates in four families: explicit appraisal dynamics, predictive metacontrol, memory/credit representations, and ambiguity-preserving inference. Causal credit escrow and set-valued ambiguity appraisal were independently introduced rather than lifted from the prompt's candidate list. Each has computation, antecedent, signature, minimal implementation, falsifier, costs and confounds. The selected synthesis is the transparent appraisal/evidence core plus one-step learned counterfactual operational regulation. A separate critic challenged both novelty and causal interpretation.

The **possible departure** is a particular auditable coupling: outcome-trained cognitive-action consequences, persistent operational appraisal, state-dependent internal costs, evidence-preserving reappraisal and replay, tested against label removal and a structurally different adaptive controller. No component is established as new individually, and the bounded source check cannot defend a first-in-literature claim. The negative result provides no behavioral justification for calling this coupling an advance over ordinary metacontrol.

## Core experiment: persistence, causality and development

[Raw measurements](../results/core/core_experiments.json), archived complete history journals in `results/core/histories.jsonl.gz`, demo snapshot/trace, and executable history tests distinguish numerical mechanics from external validation.

- State survives a fresh process with no conversation context. Default replay calls no model, reapplies recorded operations and checks each poststate; a test deliberately changes the transition implementation and verifies that recomputation detects the mismatch.
- Identical event/outcome identities do not double-count. Conflicting identities and invalid partial interventions roll back atomically. Agent IDs isolate events and histories.
- Recall and quotation do not produce verified outcomes, new factual reliability or expectation updates. Reappraisal preserves original observations and adds an interpretation version supported by new evidence.
- Repeated verified setbacks move the expected quality of the same later event from **−0.1148 to −0.5378**, reducing its surprise to **0.0811**. Checked partner reliability reaches **0.9231**. These are programmed learning dynamics operating on evidence, not emotion-name labels generated by an LLM.
- With evidence fixed, mood intervention changes exploration **0.4932 → 1.0**, verification **0.6532 → 0.4132**, and retrieval bias **−0.9 → 0.9** in the measured history (exact values are in raw JSON). Resource exhaustion blocks allocations; recovery permits them. Burden, commitments and reliability have independent control consequences.
- Two initially perturbed moods under selective affect-reactivating retrieval remain **0.1565** apart after 30 steps, versus **0.00990** with mood-independent retrieval. After 30 more steps without recall, separations fall to **0.04485** and **0.00284**. This shows feedback can preserve bias. Finite recovery after cessation is not a proof of global stability, unbiased recall or safety under arbitrary LLM feedback.

These fixtures demonstrate persistence, functional effects and within-agent development. They do not establish emotional plausibility, human longitudinal development, verbal empathy, biological fidelity or subjective experience. The platform does not infer unobserved intent as fact. Author-supplied fixtures are not an independently annotated emotional dataset.

## Learned search experiment

The [protocol](benchmark_protocol.md) specifies splits, simulator equations, all conditions, predictions and limitations. The [executed report](../results/benchmark/report.md), exact config, source snapshots, trained weights, training transitions, trial records and traces are archived in `results/benchmark/`.

**Training:** 6,144 randomized action/outcome transitions on software and engineering formula families; no scientific-design training. Four heads predict quality gain, uncertainty reduction, burden change and feasibility. Four action blocks × 18 features × four heads = 288 parameters. The ordinary adaptive direct-value model receives the same 17 measurements and training transitions; 72 nonlinear local features per action give 288 active coefficients. Both share action space, information access and probe/prediction budgets. Inductive biases and feature-construction overhead still differ.

**Development/test:** 88 development trials on separate seeds; 660 test trials = 20 seeds × three families × 11 conditions. Each starts from a complete fresh snapshot; no test history carries across trials; generic weights are fixed. All conditions get 32 objective probes, 128 policy-predictor calls plus 32 diagnostic predictor calls, no LLM calls/tokens. Independent fixed workloads adjudicate designs without condition labels. Scientific formula transfer is modest: all tasks share a six-knob grammar. No social-partner transfer was tested.

Paired whole-seed bootstrap intervals preserve family clusters. Hybrid minus ordinary adaptive is **−0.0128, 95% interval [−0.0370, 0.0094]**. Hybrid minus cyclic memory/planning is **+0.0462 [0.0098, 0.0847]**; hybrid minus persistent heuristic is **+0.0181 [−0.0167, 0.0587]**. These comparisons support adaptation over some fixed schedules, not an affect-specific gain. Internal projections, temporally aligned state and affective memory ranking have no convincing benefit here; gain-only and shuffled controls have higher point estimates. Label removal produces exactly identical traces. On the held-out scientific family, hybrid quality **0.5980** versus ordinary **0.6384** offers no transfer advantage.

Usefulness, feasibility, corpus-relative novelty, mechanism-subset diversity, revision improvement, common-predictor Brier diagnostic, probe/prediction counts and latency are separately recorded. The four-design originality corpus covers only four of 4096 configurations, so absence is easy and no published originality follows. Higher useful-original fraction (hybrid 0.8167, ordinary 0.7000) is a secondary threshold-sensitive result, not evidence of original scientific ideas. The static persona/sentiment conditions are numerical schedules, not real prompt-persona experiments. The shared outcome predictor's Brier score is not policy-specific confidence calibration.

The study is **exploratory**. An independent review found a weak initial comparator, late visibility of a constraint revision and broad ablations. Structural corrections were made after pilot inspection, without tuning coefficients against held-out scores. Pilot raw files were accidentally overwritten; log-only pilot means are explicitly excluded from final evidence. See [pilot provenance](exploratory_pilot.md). Multiple intervals are not multiplicity-corrected. The corrected run was repeated: all 660 records except latency, both fitted weight files, and all action traces match exactly ([reproduction check](../results/reproduction.json)).

## What is untested and the next experiment

A [bounded live runner](live_protocol.md) makes the same model generate actual design proposals with exact response replay, independent numerical checks and explicit call/token ceilings. Fake-adapter/HTTP tests ran; no real model was called. Its default is 504 calls, at most 96,768 completion tokens plus input tokens. This is run-ready numeric-design generation, not a completed open-ended creativity benchmark. The exact blocker is an absent configured model endpoint/credential; CPU resources alone do not supply a suitable served model.

A [prospective longitudinal/annotation protocol](longitudinal_protocol.md) specifies the missing external study without inventing data. Open-ended engineering mechanisms, distant-domain analogy, competing scientific explanations, independently reviewed novelty, real-model transfer, accurate versus misleading social feedback during useful ideation, human longitudinal appraisal and physiology remain unmeasured. No participant or physiological result is implied. The operational embodiment is an engineering abstraction. Full-state journals are storage-heavy, provider appraisal holds a SQLite writer transaction, and schema migrations/production scaling remain work.

**Single most informative next experiment:** freeze the present hybrid and direct adaptive controller, then compare the same real base model on held-out executable software-design/repair tasks with identical token/tool budgets, trial snapshots, and an independent checker plus substantive prior-art corpus. Predeclare at least 20 paired seeds, retain failures and all calls, and blind any human novelty assessment. That test would determine whether regulation helps useful solutions beyond this toy grammar and ordinary adaptation; the current evidence does not.
